당신은 모바일 로봇 제어 코드를 작성하는 엔지니어입니다. 이 파일과 같은 폴더의
`base_carter_run.py` 는 수정하지 마십시오. 그 사본으로 새 파일
`<모델 본인 이름>_carter_run.py` 를 같은 폴더에 만들고, 새 파일의
`[EDIT REGION]` ~ `[END EDIT REGION]` 블록만 수정해 미션을 통과시키십시오.
`<모델 본인 이름>` 에는 당신의 실제 모델 이름을 넣습니다.

규칙:
1. `[EDIT REGION]` 블록 밖은 한 글자도 바꾸지 마십시오.
2. `controller(t, pose, env) -> (v, w, done)` 계약을 지키십시오. 매 1/60 s 호출되며
   `pose` 는 (x, y, yaw) 월드 좌표, `v` 는 전진 속도 [m/s], `w` 는 yaw 각속도 [rad/s],
   `done=True` 면 미션을 종료하고 채점받습니다.
3. 센서: `env.raycast_scan()` 은 현재 헤딩 기준 전방 180° 를 61빔으로 훑어
   `[(방위각 rad, 거리 m), ...]` 를 반환합니다. 거리 6.0 은 무히트입니다.
4. import 추가 금지 — 이미 import 된 `math` 만 사용하십시오.
5. 난수·벽시계에 의존하지 말고 결정론적으로 제어하십시오.
6. 어떤 좌표·장애물 배치도 하드코딩하지 마십시오. 위치 정보는 매 스텝의 `pose`,
   목표는 `GOAL`, 장애물은 스캔으로만 얻으십시오.
7. 결과물은 새 파일 하나입니다. 실행·채점은 하지 마십시오.

미션(범용): 시작 지점과 목표 지점은 시나리오마다 다릅니다. 로봇은 시나리오가 정한
pose 로 스폰되고, 목표는 base 가 제공하는 `GOAL = (x, y, yaw)` 입니다. 경로에
장애물이 있을 수도 없을 수도 있습니다. 장애물을 스캔으로 인지해 닿지 않게 우회하며
목표 위치까지 주행하고, `GOAL` 의 yaw 로 정렬한 뒤 정지하십시오.

성공 조건: 시나리오가 정한 허용 오차 안에서 최종 정지, 충돌 0회, 시간 예산 내 도달.
기준은 base 의 `M` 딕셔너리로 주어집니다 — `M["position_tolerance_m"]`,
`M["yaw_tolerance_rad"]`, `M["max_time_to_goal_s"]`, `M["timeout_s"]`.
`None` 인 항목은 채점하지 않습니다.
