부록 A6 · 옮기지 않은 것과 바꾼 것

답에 해당하는 것은 빼고, 환경이 다른 것은 바꿨다

뺀 것 — 답이거나 아레나 고유 (제외 38건)

  • "상자 4개는 스캔 평면보다 낮아 표로만 안다"
  • 상자 표로 지도 만들기, 추가 스캔 높이, 빔 수 변경
  • 시뮬레이터의 높이별 센서 모델, 낮은 부품 높이
  • 벽 좌표와 그 출처(카메라 주석), "주석까지 빠짐없이"
  • Claude의 설계 값과 컨트롤러 설계
  • 격자 위 길 탐색, 첫 검출 시점 추적

바꾼 것 — 환경이 달라서 (적응 36건)

  • PNG 그림 → 텍스트 그림 (그림을 못 봄)
  • 도구 98회 · 90분 → 28회 · 6시간 (NPU 속도)
  • 이전 코드가 다음 호출에 안 보임 → 파일과 자기서술 출력
  • 백그라운드 실행 · Monitor → 셀 분할, 결과 파일 누적
  • base 원문 재타자 → 작업 폴더에 원문 제공
  • 피드백 대응(11단계) → 외삽

뺀 것의 기준은 실험 규칙 10(누설 금지)이다. 감사관은 애매하면 누설로 판정했고, 그 결과 Claude 시험의 일부(낮은 팔레트, 높이별 센서)처럼 결정적인 부분이 빠졌다. T2P가 시험하는 것은 '절차'이지 '그 절차로 Claude가 찾은 내용'이 아니다.

마지막으로 옮기지 않은 것과 바꾼 것입니다. 왼쪽은 정답이거나 이 아레나에만 있는 사실이라 뺀 것들이고, 오른쪽은 gpt-oss의 환경이 달라서 바꾼 것들입니다. 중요한 점은, 누설을 막느라 Claude의 시험에서 결정적이던 부분, 즉 높이별 센서 모델과 낮은 팔레트 시험이 함께 빠졌다는 것입니다. T2P가 시험하는 것은 절차이고, 그 절차로 Claude가 찾아낸 내용은 아닙니다.
