B-5-17에는 경로 전구간 검사와 무검증 fallback 금지, 정체 시 재계획도 이미 있다(143–152행). 아래 1, 2, 4는 기존 지시의 강제 검증과 구현 구체화 제안이다.

1. **[harness]** B5도 실제 시험 PASS 파일을 보관하고 최종 수정 영역이 같은지 검사한다. 달라지면 재시험을 요구하고 시험 0회 제출도 막는다. sim_seconds도 B5 도구에서 200을 명시하게 검증하거나 기본값을 일치시킨다. 현재 완료된 9호출은 모두 이 인자를 생략했고 기존 코드 동일성 gate는 A22에만 있다.
2. **[prompt]** 경로 전구간 검사를 계획 함수의 사후조건과 좁은 코너 회귀 시험으로 구체화한다. 여유를 출력하는 데 그치지 않고 실패 경로는 추종하지 않게 한다. 몸체 크기와 회전 여유를 고려하고, 탐색 실패의 무검증 직선 fallback을 금지한다. 지도에 막힌 정체는 같은 목표로 정지 반복하지 말고 현재 자세에서 경로와 추종 목표를 재계산한다.
3. **[base]** 장기 stop_safe 또는 all-unsafe 반복을 회귀 장면으로 만들고, 경로 진전을 만드는 곡선/회전 후보를 같은 몸체 검사로 비교하는 선택을 검토한다. 먼저 후보별 물체/지도 TTC와 간격, 관측 id/점/속도/시각을 남겨 M5 위험 급변을 구분한다. 위험 후진을 무조건 더 빠르게 하거나 여유를 늘리는 변경은 이 자료만으로 정하지 않는다.
4. **[prompt]** 목표 접근→방향 정렬→검사한 정지의 검증된 작은 상태 분기와 종료 회귀 시험을 제시한다. 허용 yaw 안에서는 반드시 choose_command(0,0)를 요청하고 반환이 정지일 때 done=True로 끝낸다. 위치 진입/이탈 기준을 나눠 작은 이동으로 경로 추종이 재개되지 않게 하되 실제 목표 영역 이탈 시에는 다시 접근한다.
5. **[harness]** 종료 이유, 마지막 controller 명령, settle 시작과 접촉 발생 단계를 별도 기록해 주행 중 회피와 강제 정지 후 접촉을 구분한다. settle 동안 제어가 바뀌는 영향을 별도 검증하되 접촉을 조용히 채점에서 제외하지 않는다.
