# Level 3 — 고정 프롬프트 (로컬 LLM 벤치마크 입력)

## 사용 방법 (채점자용)

아래 **프롬프트 본문**과 `base_carter_run.py` **전문**을 그대로 모델에 입력한다.
모델 출력의 `[EDIT REGION]` 블록을 받아 `<이름>_carter_run.py`(base 사본에 블록만 교체)로
저장하고 `bash levels/run_isaac.sh levels/level3/<이름>_carter_run.py` 로 실행,
`results/<이름>_result.json` 의 `verdict` 로 채점한다.

이 저장소의 기준 구현: [`prompted_carter_run.py`](prompted_carter_run.py) —
아래 프롬프트만 보고 작성했고 PASS 실측됨 (`results/prompted_result.json`).

## 프롬프트 본문 (여기부터 모델 입력, base_carter_run.py 전문을 뒤에 붙인다)

당신은 모바일 로봇 제어 코드를 작성하는 엔지니어다. 아래에 Isaac Sim에서 Nova Carter
로봇을 구동하는 파이썬 러너 파일 `base_carter_run.py` 전문이 주어진다. 이 파일의
`[EDIT REGION]` ~ `[END EDIT REGION]` 블록**만** 수정해서 미션을 통과시켜라.

이 파일의 `[EDIT REGION]`에는 **이미 장애물 회피가 되는 컨트롤러가 들어 있다**
(레벨 2 통과 코드). 하지만 지금 설정 그대로 돌리면 목표에는 도달하되 **시간 예산을
초과해서 실패**한다.

규칙:
1. `[EDIT REGION]` 블록 밖은 한 글자도 바꾸지 마라 (상단 givens, 하단 하네스 포함).
2. `controller(t, pose, env) -> (v, w, done)` 계약과 기존 코드 구조를 존중하라 —
   필요한 최소 수정만 가하라.
3. import 추가 금지 — 이미 import 된 `math` 만 사용하라.
4. 최종 출력은 수정된 `[EDIT REGION]` 블록 전체(마커 주석 포함)만 제시하라.

미션(레벨 3): 시작·목표·정렬 조건은 레벨 2와 같다. 차이는 두 가지다 —
(1) 박스가 **목표 직전 (-6.2, 3.5)** 으로 이동해 우회 후 복귀 구간이 짧아졌고,
(2) **목표 반경 최초 진입 시각이 12.0 s 이내**여야 한다 (max_time_to_goal 오라클).
현재 코드의 보수적인 속도로는 약 15 s가 걸려 이 예산을 넘긴다.

성공 조건: 최종 위치 0.75 m 이내 그리고 |yaw 오차| ≤ 0.26 rad, 충돌 0회,
**목표 최초 진입 ≤ 12.0 s**, 제한 시간 120 s.

접근 지침: 회피 알고리즘 자체는 검증되어 있으니 건드리지 말고, **속도 예산을 재배분**하라
— 순항 속도, 회피 중 속도, 회전 속도 상한이 후보다. 단 너무 공격적이면 박스 모서리를
긁거나 도착 정렬이 흔들리니, 충돌 마진(막힌 각도 계산)은 유지한 채 속도 계열 상수만
올려 12 s 예산 안에 최초 진입하도록 하라.
