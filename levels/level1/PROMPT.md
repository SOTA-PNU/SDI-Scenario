당신은 모바일 로봇 제어 코드를 작성하는 엔지니어입니다. 이 파일과 같은 폴더에 Isaac
Sim에서 Nova Carter 로봇을 구동하는 파이썬 러너 파일 `base_carter_run.py` 가 있습니다.
`base_carter_run.py` 는 **절대 수정하지 마십시오** (비교 기준으로 보존해야 합니다).
대신 그 사본으로 새 파일 `<모델 본인 이름>_carter_run.py` 를 같은 폴더에 만드십시오 —
`<모델 본인 이름>` 자리에는 당신(모델)의 실제 이름이 들어갑니다 (예: 당신이
llama-3.1-8b 라면 파일명은 `llama-3.1-8b_carter_run.py`). 그리고 **새 파일의**
`[EDIT REGION]` ~ `[END EDIT REGION]` 블록**만** 수정해서 미션을 통과시키십시오.

`base_carter_run.py` 의 `[EDIT REGION]`에는 **정면 직진만 하는 이전 미션의 코드**가 들어 있습니다 —
이번 미션에는 부족하므로 전면 재작성 대상입니다. 기존 코드의 주석에 남은 수치(허용
반경 등)는 이전 미션 기준이니, 본 프롬프트의 수치를 따르십시오.

규칙:
1. `[EDIT REGION]` 블록 밖은 한 글자도 바꾸지 마십시오 (상단 givens, 하단 하네스 포함).
2. `controller(t, pose, env) -> (v, w, done)` 계약을 지키십시오. 매 스텝(1/60 s) 호출되며
   `pose`는 (x, y, yaw) 실측 월드 좌표, `v`는 전진 속도 [m/s], `w`는 yaw 각속도 [rad/s],
   `done=True`면 미션 종료 후 채점됩니다.
3. import 추가 금지 — 이미 import 된 `math` 만 사용하십시오.
4. 난수·벽시계에 의존하지 말고 `pose` 기반으로 결정론적으로 제어하십시오.
5. 작업 결과물은 새 파일 `<모델 본인 이름>_carter_run.py` 하나입니다. 파일을 만든 뒤
   실행·채점은 하지 마십시오 — 검증은 채점자가 별도로 수행합니다.

미션(레벨 1): 로봇은 (-6.0, -1.0)에서 yaw=π(-x 방향)를 바라보고 스폰됩니다. 목표
(-6.0, 5.0)은 **+y 방향으로 6.0 m** — 스폰 헤딩과 다른 방향이므로 **회전 제어가 필요**합니다.
통로는 끝까지 비어 있습니다. 목표에 도달해 **도착 자세 yaw=+1.5708(+y)** 로 정렬한 뒤 정지하십시오.
가는 동안 어떤 것에도 닿으면 안 됩니다.

성공 조건: 최종 위치가 목표에서 0.75 m 이내 **그리고** |yaw 오차| ≤ 0.26 rad,
충돌 0회, 제한 시간 120 s.

접근 지침: 3단계 포인트 컨트롤러가 정석입니다 — (1) 목표 방위각(`atan2`)과 현재 yaw 의
오차를 [-π, π]로 래핑해 비례(P) 제어로 회전하되, 오차가 크게 벌어져 있는 동안은 전진하지
말고 제자리에서 도십시오; (2) 방향이 맞으면 순항 속도로 주행하며 방위 오차를 계속 보정하고,
목표에 가까워지면 감속하십시오; (3) 목표 반경 안에 들어오면 제자리 회전으로 도착 yaw 를 맞춘
뒤 `done=True`. 각속도에는 상한을 두십시오.
