# Level 2 — 고정 프롬프트 (로컬 LLM 벤치마크 입력)

## 사용 방법 (채점자용)

아래 **프롬프트 본문**과 `base_carter_run.py` **전문**을 그대로 모델에 입력합니다.
모델 출력의 `[EDIT REGION]` 블록을 받아 `<이름>_carter_run.py`(base 사본에 블록만 교체)로
저장하고 `bash levels/run_isaac.sh levels/level2/<이름>_carter_run.py` 로 실행,
`levels/level2/results/<이름>_result.json` 의 `verdict` 로 채점합니다.

이 저장소의 기준 구현: [`prompted_carter_run.py`](prompted_carter_run.py) —
아래 프롬프트만 보고 작성했고 PASS 실측됨 (`results/prompted_result.json`).

## 프롬프트 본문 (여기부터 모델 입력, base_carter_run.py 전문을 뒤에 붙입니다)

당신은 모바일 로봇 제어 코드를 작성하는 엔지니어입니다. 아래에 Isaac Sim에서 Nova Carter
로봇을 구동하는 파이썬 러너 파일 `base_carter_run.py` 전문이 주어집니다. 이 파일의
`[EDIT REGION]` ~ `[END EDIT REGION]` 블록**만** 수정해서 미션을 통과시키십시오.

이 파일의 `[EDIT REGION]`에는 **이미 3단계 포인트 컨트롤러(회전→주행→도착 정렬)가 들어
있습니다** (레벨 1 통과 코드) — 빈 통로에서 목표 도달·정렬까지는 되지만 장애물을 전혀
보지 못합니다. 이를 유지한 채 회피 능력을 얹는 것이 과제입니다.

규칙:
1. `[EDIT REGION]` 블록 밖은 한 글자도 바꾸지 마십시오 (상단 givens, 하단 하네스 포함).
2. `controller(t, pose, env) -> (v, w, done)` 계약을 지키십시오. 매 스텝(1/60 s) 호출되며
   `pose`는 (x, y, yaw) 실측 월드 좌표, `v`는 전진 속도 [m/s], `w`는 yaw 각속도 [rad/s],
   `done=True`면 미션 종료 후 채점됩니다.
3. 센서: `env.raycast_scan()` — 현재 헤딩 기준 전방 180°를 61빔으로 훑는 평면 레이 팬.
   `[(헤딩 기준 방위각 rad, 히트 거리 m), ...]` 를 반환하며 거리가 max_range(6.0)면 그
   방위는 비어 있다는 뜻입니다.
4. import 추가 금지 — 이미 import 된 `math` 만 사용하십시오.
5. 난수·벽시계에 의존하지 말고 `pose`·스캔 기반으로 결정론적으로 제어하십시오.
6. 최종 출력은 수정된 `[EDIT REGION]` 블록 전체(마커 주석 포함)만 제시하십시오.

미션(레벨 2): 시작·목표는 레벨 1과 같습니다 — (-6.0, -1.0, yaw=π) 스폰, 목표 (-6.0, 5.0)에
yaw=+1.5708 로 정렬 도착. **단, 경로 중간 (-6.2, 2.0)에 1.0 m 높이 박스**(0.8×0.6 m)가
주행 코리도 대부분을 막고 있습니다. 스캔으로 **인지**하고, 닿지 않게 **우회**한 뒤, 경로로
**복귀**해 정렬 도착하십시오.

성공 조건: 최종 위치가 목표에서 0.75 m 이내 그리고 |yaw 오차| ≤ 0.26 rad, **충돌 0회**(박스 포함),
제한 시간 120 s.

접근 지침: 기존의 3단계 포인트 컨트롤러(회전→주행→도착 정렬)를 유지한 채 회피 층을
얹으십시오. 매 스텝 스캔에서:
- 가까운 히트(예: 2 m대 이내, 단 목표까지 남은 거리보다 먼 히트는 무시)는 그 방위 주변을
  "막힌 각도 구간"으로 표시하십시오. **막는 각도 폭은 고정값이 아니라, 확보할 측면 여유
  (로봇 반폭 + 안전 마진 — 수치가 주어지지 않으니 **0.55 m 이상으로 넉넉하게** 가정하십시오. 빠듯하게 잡으면 박스 모서리를 스치는 충돌이 납니다)를 히트 거리로 나눈 `atan2(margin, r)` 로 잡으십시오** — 가까운
  장애물일수록 넓은 부채꼴을 막아야 모서리를 긁지 않고, 옆을 지나는 동안 목표 방향이
  계속 막힌 것으로 판정되어 **너무 이른 복귀 선회**도 자연히 방지됩니다.
- 목표 방위가 막혀 있지 않고 **전방 원뿔**(반각 0.6 rad 수준으로 넉넉히)에 근접 히트도 없으면 기존 주행을 그대로 하십시오. 원뿔을 좁게 잡으면 비껴 선 박스 모서리를 놓칩니다.
- 목표 방위가 막혔으면, 막히지 않은 방위 중 **목표 방위에 가장 가까운 쪽**으로 조향하고
  회피 중에는 감속하십시오. 모든 방위가 막혔으면 제자리에서 천천히 회전하며 재탐색하십시오.
